# TEP4100 Fluidmekanikk — Kræsjkurs Vår 2026

127 sider håndskrevne notater laget til Teknas kræsjkurs i Fluidmekanikk ved NTNU. Bygget av Bilal Sheikh basert på åpent tilgjengelige eksamensoppgaver (2010–2025), øvinger og løsningsforslag fra faget — uten å ha tatt kurset selv.

## Innhold

- **Sentrale begrep** — viskositet, tetthet, skjærspenning, no-slip betingelse, Newtonsk fluid
- **Fluidstatikk** — trykkfordeling, hydrostatikk, manometre, trykkraft på plane og buede flater, trykksenter, oppdrift og flytevilkår
- **Kinematikk** — strømlinjer, kontinuitetslikning, akselerasjon, strømfunksjon og hastighetspotensial
- **Bernoulli og energilikning** — friksjonsfri og generalisert Bernoulli, pump- og turbinhøyde, Darcy-Weisbach, tapsledd og iterativ løsning for rørstrøm
- **Kontrollvolum** — impuls- og kraftbalanse, bevegelig kontrollvolum, relativt koordinatsystem
- **Navier-Stokes** — laminær kanalstrøm, Couette–Poiseuille, filmstrøm, annulær strøm, randebetingelser
- **Roterende fluid** — sentrifugaltrykk, parabolsk fri overflate, volumbevarelse
- **Grensesjikt** — δ(x), skjærspenning τ_w, dragkoeffisient, laminær og turbulent regime
- **Dimensjonsanalyse og similaritet** — Buckingham π-teorem, karakteristiske skalaer
